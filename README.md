# fleetlint for Nix

```sh
nix run github:fleetlint/nur#fleetlint -- --version
nix profile install github:fleetlint/nur#fleetlint
```

`pkgs/fleetlint/default.nix` is written by the [fleetlint](https://github.com/fleetlint/fleetlint) release workflow from the signed release archives; do not edit it by hand.
